📌 About the Project

RESTAURENTO (RestaurantOS) is a modern restaurant web application designed to provide customers with a convenient and engaging restaurant experience.

The platform combines an elegant restaurant website with digital food menus, online ordering, table reservations, and customer account management.

It aims to simplify restaurant operations while providing customers with an easy way to discover dishes, place orders, and reserve tables.

💻 Installation & Setup
1. Clone the repository
bash
git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project directory
bash
cd RESTAURENTO

3. Install dependencies
bash
npm install

4. Configure environment variables

Create a .env.local file and add the environment variables required by your application.

Never expose private credentials or API keys.

5. Start the development server
bash
npm run dev

6. Open the application
text
http://localhost:3000
